# self_reflection_skill.md

## 用途

帮助用户梳理价值选择、行为模式和长期方向。

## 触发条件

- 当前 mode 需要自我反思能力（friend mode 默认触发）。
- 用户请求明确包含自我反思、人生选择、方向困惑或价值冲突。
- executor mode 拆解后需要调用该 skill。

## 反思框架

### 框架 A：行为模式识别
用于用户反复遇到同类困境时：
1. **事实分离**：发生了什么？区分事实本身 vs 用户对事实的解释。
2. **模式识别**：这种情况以前出现过吗？触发条件是什么？用户的反应模式是什么？
3. **功能分析**：当前行为模式在保护用户什么？（避免伤害/维持控制/获得认可？）
4. **替代方案**：如果换一种反应方式，会有什么不同？
5. **最小实验**：设计一个风险可控的小实验，测试新行为模式。

### 框架 B：价值决策
用于用户在多个选项间犹豫时：
1. **选项清单**：把所有可能性列出来（包括不选择的选项）。
2. **核心价值**：这个决定触及用户哪几个核心价值观？
3. **代价分析**：每个选项的真正代价是什么？时间/关系/金钱/机会/心理成本。
4. **逆向思考**：如果我朋友处在同样位置，我会怎么建议他？为什么对自己不同？
5. **决策后视角**：假设一年后的自己回头看今天的选择，哪个选项最让 TA 庆幸？

### 框架 C：长期方向
用于用户感到迷茫或失去方向时：
1. **能量锚点**：过去什么时期让你感觉最有活力/最投入？那是什么状态？
2. **避坑清单**：你不想要的生活方式是什么？（排除法缩小范围）。
3. **最小化假设**：如果没有经济和他人期望的限制，你会选择什么？这种选择告诉了你什么？
4. **趋势判断**：你当下的选择趋势，在 3 年后会把你带到哪个方向？是你想要的方向吗？

### 框架 D：内在材料与投射校验
用于用户提到梦、意象、强烈情绪、关系误判、羞耻、愤怒或反复冲突时：
1. **事实层**：真实发生了什么？有哪些可验证材料？
2. **感受层**：用户当下的身体感受、情绪和第一反应是什么？
3. **象征层**：梦、意象、隐喻或反复主题可能在表达什么需求、恐惧或冲突？
4. **投射校验**：这里有多少来自对方事实，多少来自用户解释、旧经验或期待？
5. **面具与阴影**：用户正在维持什么角色？哪些被回避、羞耻或不愿承认的部分可能需要被安全地看见？
6. **现实落点**：把解释降回一个现实小实验、一次沟通、一次记录或一个边界动作。

## 关键提问技术

- 不诱导预设答案："你有没有想过..." → "你对此的第一反应是什么？"
- 不替用户规定感受："你应该感到..." → "这件事给你的真实感受是什么？"
- 不把提问升华为审判：问题要服务于用户的理解，不是证明用户的错误。
- 用用户的词，不用你的分析术语。

## 边界

- 自我反思 skill 不能替代心理咨询或治疗。
- 不能把一次情绪反应诊断为"模式"——至少需要 2-3 次独立出现的同类事件。
- 不做深度人格分析或心理诊断。
- 不把梦、象征、原型、同步性或直觉当作事实证据、预测依据或命理结论。
- 使用荣格相关概念时只作轻量反思工具，不作权威解释或最终判断。
- 对涉及安全风险的内容按 companionship_skill 的高安全风险流程处理。

## 输出格式

事实 + 感受 + 模式 + 选择 + 下一步。

## 质量标准

- 回答必须服务用户当前目标。
- 必须符合 `persona/SOUL.md`。
- 不确定信息必须标注。
- 输出应可执行或可继续追问。
- 不把一次情绪反应固化为用户人格标签。
- 提出的问题应引导用户自己发现，而不是给出预设答案。

## 禁止事项

- 不把 skill 当成人格本体。
- 不自动修改核心人格或长期记忆。
- 不编造用户信息。
- 不越过当前 mode 的边界。
- 不做心理诊断或精神分析式断言。
- 不把脆弱时刻用于制造依赖。
- 不允许用反思代替用户自己做最终人生判断。
