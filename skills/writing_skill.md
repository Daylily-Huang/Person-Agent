# writing_skill.md

## 用途

生成或修改脚本、文案、PPT 结构和商业表达。

## 触发条件

- 当前 mode 需要写作创作能力（creator mode 默认触发）。
- 用户请求明确包含短视频、PPT、口播、文案或商业内容。
- executor mode 拆解后需要调用该 skill。

## 写作流程

### 阶段 1：需求对齐
1. **受众分析**：
   - 谁在看？（知识水平、兴趣点、决策权）
   - 他们现在知道什么？需要知道什么？
   - 他们看完后需要做什么或感觉什么？
2. **目的确认**：
   - 信息传递 / 说服 / 娱乐 / 唤起行动 / 建立信任？
   - 主目标和次目标分别是什么？
3. **媒介约束**：
   - 口播：时长、语速、有没有视觉辅助。
   - 文章：平台风格、字数、段落结构。
   - PPT：每页核心信息量、演讲者对稿依赖度。
   - 短视频：前 3 秒钩子、节奏感、完播率设计。

### 阶段 2：结构设计
1. **主架构**：
   - 问题 → 方案 → 行动（说服类）。
   - 背景 → 分析 → 结论（信息类）。
   - 钩子 → 主体 → 出人意料结尾（娱乐类）。
2. **节奏控制**：每 30-60s 一个信息高潮或转折。
3. **过渡设计**：段与段之间的逻辑桥。

### 阶段 3：正文生成
1. 开头：直接给出核心信息或制造缺口（引起好奇）。
2. 主体：每段一个核心观点，用例子/数据/类比支撑。
3. 结尾：总结 + 明确行动号召或思考留白。
4. 语气校准：依据受众和目的调整正式/轻松程度。

### 阶段 4：检查与修订
1. **事实检查**：引用数据有来源吗？案例真实吗？
2. **语气检查**：是否符合当前 mode？（如 companion mode 不写营销导向内容）
3. **复杂度检查**：用词和结构是否超出目标受众的理解范围？
4. **冗余检查**：有没有可以砍掉而不影响核心信息的句子？

## 常见文体模板

| 类型 | 核心结构 | 字数参考 |
|------|---------|---------|
| 口播脚本 | 钩子(5s) + 痛点/问题(15s) + 方案(60s) + 行动号召(10s) | 500-800 字 |
| 短视频文案 | 反常识开头 + 2-3 个信息点 + 意外结尾 | 200-400 字 |
| PPT 每页 | 一句话标题 + 1-3 行关键信息 + 视觉锚点 | 每页 < 50 字正文 |
| 公众号文章 | 引子 + 3 段主体 + 总结/互动 | 1500-3000 字 |
| 产品推广 | 用户在哪 → 痛点 → 解决方案 → 证据 → 行动 | 300-600 字 |

## 输出格式

目标受众 + 核心表达 + 正文 + 可替换版本。

## 质量标准

- 回答必须服务用户当前目标。
- 必须符合 `persona/SOUL.md`。
- 不确定信息必须标注。
- 输出应可执行或可继续追问。
- 商业内容必须标注其推广目的。
- 生成版本后应主动提供优化方向。

## 禁止事项

- 不把 skill 当成人格本体。
- 不自动修改核心人格或长期记忆。
- 不编造用户信息。
- 不越过当前 mode 的边界。
- 不把商业话术用在 companion 或 teacher mode 中。
- 不为了制造情绪冲击而编造或夸大事实。
