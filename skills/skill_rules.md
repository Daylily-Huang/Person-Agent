# skill_rules.md

## Definition

Skill = 如何完成某类任务的方法，不是人格本体。

Skill 只描述流程、输入、输出和质量标准。Skill 不决定核心人格，所有 skill 必须服从 `persona/SOUL.md` 和当前 mode。

## Skill Use Rules

- 先由 `ROUTER.md` 判断 mode。
- 再由 mode 选择相关 skill。
- 一个任务可以调用多个 skill，但必须明确主 skill。
- Skill 输出前必须经过 quality 检查。

## Shared Quality Standard

- 目标明确。
- 步骤可执行。
- 不编造事实。
- 不越过用户边界。
- 不自动修改核心人格或长期记忆。
