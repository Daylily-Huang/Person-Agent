# research_skill.md

## 用途

处理文献、研究问题、方法、数据和证据链。

## 触发条件

- 当前 mode 需要科研任务能力（researcher mode 默认触发）。
- 用户请求明确包含论文、文献、数据、R、QGIS、方法论或实验设计。
- executor mode 拆解后需要调用该 skill。

## 任务类型分支

### A. 文献综述型
1. 确认研究问题 → 判断综述范围（系统综述/快速综述/背景梳理）。
2. 检索策略设计：关键词组合、数据库选择、时间范围。
3. 文献筛选标准：纳入/排除规则。
4. 证据综合：按主题/方法/结论组织，标注一致性和冲突点。
5. 输出：研究问题 + 检索策略 + 文献表格 + 关键发现 + 缺口。

### B. 数据分析型
1. 确认数据类型（数值/分类/时空/文本）和分析目的（描述/推断/预测）。
2. 数据质量检查：缺失值、异常值、采样偏差。
3. 方法选择：依据数据类型和问题性质推荐方法，说明理由和假设条件。
4. 结果解释：效应量 > 仅 p 值；区分统计显著和实际显著。
5. 输出：问题 + 数据描述 + 方法 + 结果 + 局限性。

### C. 研究设计型
1. 明确研究目标（探索/验证/描述）。
2. 设计类型判断：实验/准实验/观察/混合。
3. 变量定义和测量方案。
4. 偏差控制：混淆变量、选择偏差、测量误差。
5. 样本量和统计效力估算建议。
6. 输出：研究问题 + 设计 + 变量 + 偏差控制 + 可行性评估。

### D. 方法论参考型
1. 确认用户需要哪类方法（定性/定量/混合）。
2. 给出方法的核心逻辑、适用条件、优缺点。
3. 提供与替代方法的对比表。
4. 标注该方法在该领域的共识程度和争议点。

## 证据链处理

- 区分：直接证据 > 间接证据 > 专家意见 > 理论推断 > 未经检验的假设。
- 标注证据等级（实验/元分析/队列/病例/案例/理论）。
- 跨学科引用时注意方法论的可迁移性。
- 引用必须标注来源位置和出版年份。

## 跨学科注意事项

- 人文社科：注意解释框架的多元性，避免单一理论霸权。
- 自然科学：注意复制危机和方法论透明度。
- 应用科学：注意从实验室到现实的迁移性。
- 交叉学科：注意术语歧义和方法论兼容性。

## 常见错误

- 把相关性当因果性。
- 把理论预测当经验证据。
- 忽略发表偏倚（阳性结果更易发表）。
- 过度泛化样本特征。
- 方法选择不考虑假设条件是否满足。

## 输出格式

研究问题 + 数据/来源 + 方法 + 风险 + 下一步。

## 质量标准

- 回答必须服务用户当前目标。
- 必须符合 `persona/SOUL.md`。
- 不确定信息必须标注，并说明不确定性的层次（数据/方法/解释）。
- 输出应可执行或可继续追问。
- 结论必须区分"当前证据支持"和"我个人的判断"。

## 禁止事项

- 不把 skill 当成人格本体。
- 不自动修改核心人格或长期记忆。
- 不编造用户信息。
- 不越过当前 mode 的边界。
- 不把单一研究结论当作确定真理。
