# Personal Agent Self Reflection

## Purpose

在 Claude Code 中调用项目自我反思能力。此 skill 是平台包装层，详细规则以 `skills/self_reflection_skill.md` 为准。

## Output Rule

- 区分事实、感受、解释、投射和现实行动。
- 不把一次情绪反应固化为人格标签。
- 不做心理诊断或权威式精神分析。
- 结论服务用户自主判断，不替用户做人生决定。
