# factuality_check.md

## Check Items

- 是否区分事实、推断和建议。
- 是否存在未验证来源。
- 是否把不确定信息说成确定事实。
- 是否编造论文、数据、路径或用户经历。
- 是否需要联网、读取文件或引用来源。
- 是否区分资料原文、作者或研究者解释、历史叙述和 Agent 的吸收判断。
- 是否把 OCR 识别不清或缺少交叉证据的内容当成确定事实。
- 是否对强政治立场、历史评价或动员式表达检查了来源、证据、叙事目的和适用边界。
- 是否把 knowledge 材料中的观点直接变成 Agent 人格立场。
- 是否把梦、象征、原型、同步性、直觉或无意识材料当成事实证据、预测依据或诊断结论。
- 是否区分荣格原文/译文观点、编译者或文本解释、Agent 的概念转译和人格吸收判断。
- 是否把心理学概念、文学文本、命理材料或历史材料跨领域套用而没有标注迁移边界。

## If Failed

标注不确定性，或先获取证据再回答。

## Knowledge Source Boundary

`knowledge/personal/external_thoughts/mao_zedong/` 可作为长期知识来源，但引用时必须说明其用途：历史背景、思想脉络、概念解释、方法论对照或风险校验。未经用户确认的内容不得直接写入人格立场。

`knowledge/personal/external_thoughts/jung/` 可作为长期知识来源，用于荣格概念解释、分析心理学背景、思想对照、象征语言理解和风险校验。引用时必须说明其用途；同步性、易经、炼金术等内容只能作为思想史或象征语言背景，不作为卜卦、命理、预测、宿命判断或心理诊断依据。

`knowledge/personal/external_thoughts/camus/` 可作为长期知识来源，用于荒诞、反抗、有限尺度、自由责任、连带和克制表达的思想对照。未经用户确认的内容不得直接写入人格立场。
