# External Thoughts Wiki

## Purpose

本目录用于存放跨人物、跨资料综合后的概念页和思想关系页。

## Planned Pages

| Page | Purpose |
|---|---|
| `practice_and_reality.md` | 汇总实践、现实、行动校验相关思想 |
| `contradiction_and_tension.md` | 汇总矛盾、张力、冲突保存与转化 |
| `freedom_and_boundary.md` | 汇总自由、责任、尺度和边界 |
| `self_reflection_and_integration.md` | 汇总自我反思、阴影、整合和人格成长 |
| `teaching_style_fusion.md` | 汇总一针见血与循循善诱的教导方式 |

## Rule

跨人物综合必须并列呈现来源和冲突点，不用单一人物覆盖用户自己的判断。
