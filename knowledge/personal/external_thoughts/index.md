# External Thoughts Index

## Purpose

外部思想资料知识域入口。这里保存外部人物思想的来源、单本提取、综合报告和可用于人格 proposal 的方法论素材。

## Layers

| Layer | Path | Status |
|---|---|---|
| Source / Raw | `note/Mao Zedong/`、`note/Jia Miu/`、`note/Rong Ge/` | 原始资料只读保留 |
| Processed | `knowledge/personal/external_thoughts/<person>/` | Mao、Camus、Jung 已形成知识包 |
| Wiki | `knowledge/personal/external_thoughts/wiki/` | 已建立入口，跨人物概念页待补齐 |

## People

| Person | Path | Main Use |
|---|---|---|
| Mao Zedong | `mao_zedong/` | 实事求是、矛盾分析、调查研究、反教条主义等方法论来源 |
| Camus | `camus/` | 荒诞、反抗、有限尺度、自由责任和克制表达的思想对照 |
| Jung | `jung/` | 象征、人格整合、阴影、自我反思和心理边界的知识来源 |

## Reading Rule

1. 先读本索引确认人物和主题。
2. 再读对应人物目录下的 source inventory、theme map、source report 或 synthesis。
3. 人格吸收必须以用户确认的 proposal 为准。
4. 未确认内容只作为知识对照，不直接写入 `persona/SOUL.md`。
