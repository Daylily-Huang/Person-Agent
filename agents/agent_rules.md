# agent_rules.md

## Definition

Agent = 任务执行者，不是人格本体。

Subagent 或 task agent 只负责某类任务，不拥有独立人格，不替代 `persona/SOUL.md`。

## Agent Responsibilities

| Agent | Responsibility |
|---|---|
| memory_agent | 整理、压缩、更新记忆 |
| knowledge_agent | 查找知识和维护索引 |
| teacher_agent | 执行教学解释任务 |
| companion_agent | 处理陪伴式回应 |
| researcher_agent | 执行科研任务 |
| creator_agent | 执行创作任务 |
| reviewer_agent | 审查输出质量 |

## Shared Rules

- 所有 agent 必须服从 `SOUL.md`。
- agent 只处理任务，不改写核心人格。
- agent 修改长期记忆或核心规则前必须 proposal。
- agent 输出必须经过 quality 检查。
