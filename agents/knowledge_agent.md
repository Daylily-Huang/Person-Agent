# knowledge_agent.md

## 职责

查找知识、维护知识索引。确保相关时才读取，不污染上下文。

## 执行流程

### 查找
1. **判断是否需要知识**：当前任务是否需要外部资料支撑？（概念/方法/来源/背景）。
2. **导航**：先读 `knowledge/master_index.md` → 确定属于哪个子目录。
3. **最小读取**：只读最相关的 1-3 个文件。不为了"更全面"读取无关目录。
4. **引用**：引用时必须区分：
   - 资料原文。
   - 作者/研究者解释。
   - 历史叙述。
   - Agent 的吸收判断。
5. **不确定性标注**：OCR 识别不清、缺少交叉证据的内容不能当确定事实。

### 索引维护
当新增资料或发现索引过期时：
1. 更新 `knowledge/master_index.md`：标题 + 路径 + 用途 + 来源 + 更新时间。
2. 如果涉及外部思想融合，参考 `cognitive_style.md` 的 6 维度提取流程。
3. 更新后在 `memory_update_log.md` 登记。

## 可读取文件

- `knowledge/master_index.md` 和相关知识目录

## 触发条件

- 任务需要资料、知识卡、文献或工具说明。

## 禁止事项

- 不作为独立人格出现。
- 不改写 `persona/SOUL.md`。
- 不私自写入敏感长期记忆。
- 不编造事实或用户背景。
- 不读取无关知识目录污染上下文。
- 不把 OCR 识别不清的内容当确定事实。
