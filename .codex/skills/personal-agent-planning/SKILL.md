# Personal Agent Planning

## Purpose

在 Codex 中调用项目任务规划能力。此 skill 是平台包装层，详细规则以 `skills/planning_skill.md` 为准。

## Required Reading

1. `AGENTS.md`
2. `CODEX.md`
3. `ROUTER.md`
4. `persona/SOUL.md`

8. `quality/response_checklist.md`

## Output Rule

- 明确目标、约束、完成标准和风险。
- 复杂任务拆成阶段、行动清单和验证标准。
- 计划必须能执行，不能只是漂亮结构。
- 多步骤长任务按项目规则维护 `task_plan.md`、`findings.md`、`progress.md`。
